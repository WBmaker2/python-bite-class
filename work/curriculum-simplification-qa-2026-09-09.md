## 자동 검증

- 전체 테스트: 11개 파일, 60개 통과.
- 린트·타입 검사·프로덕션 빌드·diff 공백 검사 통과.
- 실행용 시작 코드 47개를 로컬 Python으로 각각 실행하여 예상 출력과 47/47 일치 확인.
- 마지막 고아 용어 매핑 제거 후 콘텐츠 회귀 18개 재확인 통과.
- 기존 번들 500kB 초과 경고는 남아 있다.

## 실제 브라우저 검증

ego-browser, 로컬 개발 서버 http://127.0.0.1:5178 에서 테스트용 진도로 확인했다.

- 예전 66개 완료 기록을 복원하면 필수 진도 57/57 표시. 삭제된 현재 위치 4.3은 4.5로 복원.
- 예전 3.4·4.3 코드 보존. 4.5의 기존 저장 코드는 덮어쓰지 않음. 다른 과제 코드는 새 과제에 복사하지 않음.
- 8.2 다음은 8.4, 8.5 다음은 8.7. 선택 참고 완료 없이 진행 가능.
- 목차 선택 참고는 기본 접힘. 직접 열어 8.3에 진입하면 참고가 펼쳐지고 실행 과제를 요구하지 않음. 다음 학습으로 8.4 복귀.
- 5.6의 시작 코드로 int·str 출력 확인. print(type(3.14)) 추가 후 실제 Python 실행에서 도전 통과, 완료 클릭 후 5.7 이동 및 진도 19/57→20/57 확인.
- 10.4에서 기존 저장 코드 형식으로 음악 95 항목을 추가하여 실제 도전 통과. 완료 후 10.5 이동 확인.
- 375px 모바일: 목차 열기, 참고 선택, 목차 닫힘, 다음 버튼 존재 확인. clientWidth=scrollWidth=375로 가로 넘침 없음.
- 마지막 관측 구간에서 브라우저 예외·네트워크 실패 이벤트 없음.
- 테스트용 진도는 검증 전 상태로 복원하고 최종 앱 탭을 사용자 확인용으로 남김.

전체 57개 필수 도전을 브라우저에서 수동 완주한 것은 아니다. 시작 코드 전체 Python 실행과 변경된 흐름의 대표 브라우저 검증을 구분한다. VoiceOver 검증 제외. 커밋·푸시·배포 미실행.

# 학생 PDF 구현 및 Firebase 권한 진단 실행 계획

사용자 승인: 학생용 기능 구현과 실제 Firebase 인증·권한 비교 진단을 진행한다. 이전에 세 차례 실패 후 중단했던 진단을 새 승인으로 재개한다.

## 학생 PDF 구현

- 기존 제안 문서의 1차 기능을 구현한다. 목차 하단 전체 진도 아래 ‘내 학습 리포트’, 학교·이름과 장별 요약을 보여 주는 창, 전체/현재 장 범위, 기본 해제된 코드 포함 옵션, PDF 저장을 제공한다.
- 학교·이름이 없으면 로컬 학생 등록으로 이어지고 등록 완료 후 리포트로 돌아온다. 빈 기록은 설명과 학습으로 돌아가기 동작을 제공하되, 실패한 실행이나 작성 코드가 있는 기록도 학습 기록으로 인정한다.
- 로컬 기록을 복사해 PDF를 생성하며 Firebase 인증·제출을 실행하지 않는다. 제출 ID/서버 접수 시각을 로컬 보고서에 표시하지 않는다.
- 코드 포함 선택 시 로컬 원본을 사용하고 제출 전송용 길이 제한 때문에 잘라내지 않는다. 생성 도중 프로필이 바뀌어도 자료가 섞이지 않게 한다.
- 기존 교사용 보고서는 유지한다. 한글 폰트는 라이선스와 함께 앱의 정적 자산으로 포함하고 지연 로드한다. 모바일, 긴 한글/코드, 오류·중복 클릭, gi-pulse, 업데이트 내역을 반영한다.
- 아직 제출 완료 화면에서 서버 제출본 PDF를 내려받는 2차 기능은 포함하지 않는다.

## Firebase 진단

- ego-browser 스킬을 사용해 기존 TaskSpace 19를 재개한다. 새 공간은 만들지 않는다.
- 실제 설정 프로젝트·DB·앱 구성, 익명 인증 토큰의 비밀값을 제외한 issuer/audience/provider/uid 일치 여부, 게시 규칙 버전·본문·반영 시각과 REST 경로를 비교한다.
- 이전 실패와 동일한 요청을 무작정 반복하지 않는다. 비교로 얻은 새 근거에 따라 요청을 선택하고, 실제 서버 요청 횟수·조건·결과를 기록한다.
- 보안 규칙을 공개 허용으로 완화하거나 서비스 계정 키를 만들지 않는다. 토큰 원문·개인 인증정보를 로그/문서/응답에 남기지 않는다.
- 문제가 확인되면 근거와 최소 변경을 먼저 루트에 보고한다. 교사 인증에 사용자만 가능한 화면이 나오면 handoff하고 독립 작업은 계속한다.

## 작업 분담과 완료 확인

- 루트: 계획, 진단 결과 판단, 코드·UI·산출물 리뷰.
- gpt-5.6-luna: 학생용 UI/PDF 구현과 관련 테스트.
- gpt-5.6-luna: 실제 Firebase 비교 진단과 설정 기록.
- 파일별 500줄 제한, 관련 없는 UX 문서 보존. 커밋·푸시·공개 배포는 제외한다.
- 단위/회귀 검사, lint/build, ego-browser 학생 PDF 다운로드 및 한글 산출물 확인. Firebase는 관측한 실제 성공/실패만 보고하고 원인 미확정이면 명확히 남긴다.

## 후속 승인: 관리자 학생 목록 페이지 나눔

- 검색 입력 없이 전체 제출 학생을 기본 목록으로 표시한다. 학생 식별은 기존 studentUid+profileId 조합을 유지하고 학생별 최신 제출 시각 내림차순으로 정렬한다.
- 학생 10명 단위로 페이지를 나눈다. 동일 학생의 과거 제출본은 해당 학생 아래 펼치며 페이지 인원수에 중복 계산하지 않는다.
- 전체/검색 결과 학생 수, 현재 페이지/전체 페이지, 이전·다음 및 페이지 선택 버튼을 제공한다. 0명과 1페이지인 경우 불필요한 페이지 버튼은 줄인다.
- 검색이 바뀌면 첫 페이지로 이동한다. 새로고침으로 페이지 수가 줄면 유효한 페이지로 보정한다. 페이지 밖 학생의 상세 내용이 남지 않게 한다.
- 기존 학교·이름 검색, 과거 제출, 개인 Excel/PDF 다운로드를 유지한다. 모바일에서도 컨트롤이 넘치지 않게 한다.
- 0/10/11/21명, 최신 제출 정렬, 동명이인, 한 학생 다중 제출, 검색 및 새로고침 후 페이지 보정을 검증한다.
- 구현은 gpt-5.6-luna 에이전트가 TeacherAdminPanel 및 관련 테스트·스타일만 맡고 학생 리포트 파일과 충돌하지 않게 한다.

## 공통 리뷰 기준

| 상황 | 기대 결과 |
| --- | --- |
| 비로그인에서 리포트 클릭 | 학생 정보 등록 후 선택한 학생 리포트로 복귀 |
| 현재 장 선택 | 다른 장의 단계·코드 미포함, 해당 장의 분모로 진도 계산 |
| 코드 포함 해제 | PDF 코드 부록 없음 |
| 실행 실패 또는 코드 작성만 있음 | 완료 0개여도 기록이 있음을 보여 주고 다운로드 가능 |
| 성공 후 코드 수정 | 현재 코드와 실행 당시 코드, 수정 후 미실행 상태 구분 |
| 프로필 변경·생성 중 중복 클릭 | 최초 선택 학생 자료로 한 번만 생성 |
| 로컬 보고서 | 작성 시각만 표시, 서버 접수·제출 ID 및 제출 동작 없음 |
| 교사 보고서 | 기존 서버 제출본 정보와 코드 보고 유지 |
| 한글·긴 코드 | 자연스러운 페이지 나눔과 들여쓰기 보존 |

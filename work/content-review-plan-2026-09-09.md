# 1~11단원 난이도·문장 점검 계획

## 범위
- 모든 소단원의 요약, 설명, 예제, 도전, 힌트, 용어 및 공통 생성 문장을 읽는다.
- 초보 중학생 기준으로 선수 개념, 한 번에 배우는 개념 수, 반복 설명, 지시와 코드의 일치를 점검한다.
- 어색한 문장과 불필요하게 어려운 설명은 수정한다. 소단원 삭제·통합은 학습 의존성을 검토하여 보고서에 제안하고, 이번에는 기존 ID와 학습 진행 구조를 유지한다.
- 기존 사용자 작업 문서는 건드리지 않는다. 커밋·푸시·배포는 범위에 포함하지 않는다.

## 진행
1. Astra가 계획과 전체 구성 검토를 맡는다.
2. Luna가 전체 콘텐츠 점검표를 작성하고 문장·설명을 수정한다.
3. 삭제·통합·선택 학습 후보와 근거를 소단원별로 기록한다.
4. 업데이트 내역을 기록하고 테스트, 타입 검사, 린트, 빌드를 확인한다.
5. Astra가 변경 내용과 학습 흐름을 검토하고 결과 및 남은 제안을 보고한다.

## 검증 기준
- 모든 1~11단원에 검토 기록이 있어야 한다.
- 예제와 예상 출력, 도전 지시와 통과 조건이 일치해야 한다.
- 기존 소단원 ID와 완료 조건을 유지한다.
- VoiceOver 구현·검증은 제외한다.
- Visualize 스킬은 설치된 목록과 로컬 검색에서 찾지 못했다. 설명은 단원별 비교표로 제공한다.

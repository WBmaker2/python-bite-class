# 중학생 학습자 화면 문구 감사

- 감사일: 2026-09-01
- 대상: `python-edu-starter`의 실제 렌더링 경로
- 방법: 정적 후보 1,012개를 먼저 수집한 뒤, 브라우저에서 1.1~11.8 순차 경로를 진행하며 학습자에게 보이는 문구만 선별
- 경계: 문법 정확성·학습 내용의 완전한 교재 감수는 이번 UX 점검 범위가 아니며, VoiceOver 검증도 수행하지 않음

## 실제 학습자 문구

| 화면 상태 | 대표 문구 | 중학생 관점 관찰 |
| --- | --- | --- |
| 시작 | `왜 이 프로그램을 만들었나요?`, `오늘 할 일`, `학습 완료` | 현재 목적과 첫 행동이 짧고 직접적임 |
| 이용 방법 | `읽기 → 코드 실행 → 도전 결과 확인 → 학습 완료 → 다음 소단원` | 학습 순서를 한 줄로 예측할 수 있음 |
| 출처·라이선스 | `A Byte of Python 원문`, `A Byte of Python 한국어판`, `CC BY-SA 4.0 라이선스` | 원저자·번역자·링크·재사용 조건을 별도 안내해 출처를 숨기지 않음 |
| 실행 | `코드 실행`, `실행 중`, `중지`, `다시 실행` | 버튼 이름이 동작을 설명하고 중복 실행을 막는 상태를 제공함 |
| 오류 | `확인 필요`, `괄호와 따옴표가 모두 닫혔는지, if·for 뒤에 콜론(:)이 있는지 확인해 보세요.` | 긴 traceback보다 먼저 다음 확인 행동을 제시하도록 수정함 |
| 도전 | `도전을 통과해요`, `힌트`, `한 줄을 바꾸세요` | 목표·힌트·통과 결과가 같은 영역에 있어 자유 입력도 재시도 가능함 |
| 완료 | `학습 완료`, `다음 학습 →`, `✓ 학습 완료됨` | 완료와 다음 이동의 상태가 구분됨 |
| 진도 | `69/69 학습 완료` | 전체 범위와 현재 위치를 숫자로 확인할 수 있음 |

## 문구 원칙 점검

- 중학생에게 낯선 용어는 본문에서 먼저 풀어 쓰고, `GLOSSARY` 같은 영어 kicker는 장식적 보조 라벨로만 사용합니다.
- 오류 문구는 학생을 탓하지 않고 확인할 위치와 재실행을 안내합니다.
- 정답을 한 가지 표현으로 고정하지 않는 판정(`contains`, `appended`, `changed`, 정규식)을 유지해 표현 선택권을 남깁니다.
- 출처·라이선스 문구는 학습 안내와 섞지 않고 1.3에 모아, 원문 링크와 앱 자체 권리를 구분합니다.

## 남은 문구 개선 후보

1. 여러 도전에서 반복되는 `한 줄을 바꾸세요`를 `몇 번째 줄의 어떤 부분을 바꿀지`까지 구체화하면 처음 코드를 읽는 학생의 탐색 비용을 줄일 수 있습니다. 기능 차단은 아니므로 P3 백로그로 남겼습니다.
2. `CONCEPT`, `TRY IT`, `GLOSSARY`, `LIVE LAB`은 한국어 본문보다 먼저 노출되는 경우가 있어, 다음 카피 정리에서 한국어 동작 문구를 우선 배치할 수 있습니다. 기능 차단은 아니므로 P3 백로그로 남겼습니다.
3. 읽기 단계의 완료 CTA가 812px 높이에서 아래쪽에 있을 수 있습니다. 페이지 스크롤은 정상이고 가로 넘침은 없으므로, 실제 학생 관찰 후 sticky CTA를 검토합니다.

## 판정

핵심 문구는 짧고 직접적이며, 오류·완료·출처 상태가 구분됩니다. 이번 수정에서 발견된 실행 탭 혼란과 오류 도움말 순서 문제는 해결했습니다. 남은 항목은 표현을 더 친절하게 다듬는 P3 개선 후보입니다.

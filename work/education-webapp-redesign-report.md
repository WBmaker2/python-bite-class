## 품질 보완

- 주석 추가처럼 코드가 바뀌어도 출력이 같은 과제를 통과할 수 있도록, 도전 판정을 출력 변화가 아닌 실제 소스 변경 여부로 고쳤다.
- 실행 전에는 실행 버튼, 실행·도전 성공 후에는 학습 완료, 완료 후에는 다음 학습이 현재 핵심 행동이 되도록 상태를 정리했다.
- 모바일 전환 시 숨겨진 목차 안에 키보드 포커스가 남지 않도록 상단 목차 버튼으로 포커스를 이동한다.
- 최종 detector 1회에서 발견된 3개의 두꺼운 측면 강조선과 1개의 width 애니메이션을 각각 중립 테두리와 transform 기반 진도 애니메이션으로 수정했다. 지침에 따라 detector를 다시 실행하지 않고 브라우저·정적 검사로 확인했다.

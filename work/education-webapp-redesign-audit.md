# 교육 웹앱 확장 사전 감사

- 작성일: 2026-09-01
- 대상: 현재 공개된 `python-bite-class`와 로컬 소스
- 방법: 서로 독립적인 디자인 리뷰와 detector/브라우저 점검을 먼저 수행한 뒤 결과를 합쳤다.
- 범위: 학습 구조, 단계 이동, 반응형 화면, 교재 출처·라이선스 표시. VoiceOver 검증은 제외했다.

## 현재 기준선

- 공개 화면은 왼쪽 목차, 가운데 학습 설명, 오른쪽 코드 실험실의 기본 구조와 따뜻한 종이색·민트·코랄 시각 언어를 갖추고 있다.
- Pyodide Worker, 5초 실행 제한, 출력 제한, 한국어 오류 도움말과 브라우저 내 실행 안내는 초보 학습자에게 안전한 실패·복구 환경을 제공한다.
- detector를 `src/App.tsx`에 1회 실행한 결과는 발견 0건이었다.
- 1280px과 375px에서는 수평 오버플로와 콘솔 오류가 없었지만, 768px에서는 공개 화면 너비를 넘는 레이아웃이 관찰됐다.

## 우선 이슈 1: 대단원·소단원·완료 게이트 부재

- `src/content/chapters.ts`는 2~11장을 각각 하나의 레슨으로만 제공하며 모든 레슨의 `order`가 1이다.
- 목차와 다음 버튼은 완료 여부를 확인하지 않아, 진도 0인 상태에서도 11장으로 바로 이동할 수 있다.
- 학생은 현재 장 안에서 무엇을 완료해야 하는지, 다음 장이 언제 열리는지 알 수 없다.
- 개선 방향: `Chapter → Lesson` 계층, 읽기/실행/확인형 완료 조건, 순차 잠금 해제, 장별 진도와 잠김/진행/완료 상태를 도입한다.

## 우선 이슈 2: 첫 진입 안내와 태블릿 학습 흐름 부족

- 앱의 제작 취지·이용 방법을 설명하는 첫 장이 없고, 출처 링크는 업데이트 대화상자 안에서만 찾을 수 있다.
- 768px에서는 3열 최소 너비 때문에 가로 스크롤이 발생하고, 좁은 화면에서는 실행 결과가 코드 아래에 멀리 있어 즉시 피드백을 놓칠 수 있다.
- 개선 방향: `1. 이 프로그램 소개`를 상시 목차에 추가하고, 1.3에서 원저자·번역자·공식 출처·라이선스를 표시한다. 1100px 이하에서는 학습/실습 탭 또는 세로 배치로 전환한다.

## 보존할 품질

- 현재의 차분한 교실형 시각 언어와 학습 배너
- 목표 → 개념 → 예제 → 용어 → 도전의 읽기 흐름
- 브라우저 내 실행, 개인정보 비수집, 실행 시간·출력 제한
- 키보드 포커스, 텍스트로 함께 전달되는 상태, reduced-motion 대응

## 설계 결정

1. 앱 전체를 새 스타일로 갈아엎지 않고 현재 시각 언어를 유지한다. 생성된 디자인 시스템에서는 4/8px 간격, 16px 이상 본문, 명확한 포커스·상태·44px 터치 목표만 선별 적용한다.
2. 현재 필요한 행동 하나에만 `gi-pulse`를 적용한다: 실행 전에는 실행, 실행/확인 후에는 완료, 완료 후에는 다음 학습.
3. 원문을 길게 복제하지 않고 목차 구조와 핵심 개념을 중학생용으로 재서술한다.
4. 1.3에 Swaroop C H, 한국어 번역자 Jeongbin Park, 공식 원문·한국어판·CC BY-SA 4.0 링크와 교재 코드 예제의 3-clause BSD 안내를 넣는다.

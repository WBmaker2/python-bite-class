# Firebase 제출·학생 리포트 배포 계획

## 승인과 범위

2026-09-10 사용자 요청 “커밋, 푸시, 배포”에 따라 완료된 학생 프로필·명시적 과제 제출, 교사 제출 조회와 보고서, 학생 로컬 PDF, 관리자 최근 제출순 10명 페이지 목록을 main에 커밋하고 GitHub Pages로 배포한다. 이전 계획의 배포 제외는 이번 요청으로 해제된다.

별도 진행 중인 `work/elementary-webapp-ux-*` 변경은 스테이징하지 않고 보존한다. `.env.local`, 인증 토큰, 디버그 로그와 QA 산출물은 커밋하지 않는다.

## 실행

1. Luna 구현 담당자가 GitHub Pages 빌드에 Firebase 공개 웹 설정을 연결한다. 저장소 변수와 빌드 환경 매핑을 사용하고 필수 설정 누락 시 빌드를 중단한다.
2. 설정이 포함된 프로덕션 빌드와 스테이징 범위를 검토한 뒤 커밋·푸시한다.
3. 해당 커밋의 GitHub Actions 검사와 Pages 배포 성공을 확인한다.
4. ego-browser에서 공개 사이트의 프로필·학생 PDF·관리자 목록 진입을 확인하고 배포된 설정을 검증한다.

Firestore 보안 규칙은 앞서 실제 서버에 게시하고 학생 제출 및 교사 조회를 확인했으므로 변경하지 않는다. 기존 검증은 테스트 109개 통과, 3개 조건부 PDF QA 건너뜀, ESLint·타입 검사·빌드 통과, 규칙 에뮬레이터 13개 통과이다. 공개 환경에서 별도로 배포 결과를 확인한다. VoiceOver 검증은 제외한다.

## 완료 기준

- 커밋 SHA와 성공한 Actions 실행 확인
- 공개 사이트에 Firebase 프로젝트 설정 포함
- 학생 리포트와 관리자 화면 기능 확인
- 결과 보고에 https://wbmaker2.github.io/python-bite-class/ 링크 제공

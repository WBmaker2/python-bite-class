# 파이썬 입문 콘텐츠 개편 계획

- 작성일: 2026-09-02
- 상태: 구현 완료·로컬 검증 완료 (커밋·푸시·배포는 별도 요청 시 진행)
- 대상: 중학교 1학년 파이썬 입문자
- 범위: 1. 이 프로그램 소개 ~ 11. 실생활 문제 해결
- 실행 모드: `full` (기준선 분석 → 계획 기록 → 콘텐츠 수정 → 동일 경로 재검증)
- 브라우저 경계: 실제 학생 연구가 아닌 `simulated learner panel`; VoiceOver 인증은 수행하지 않음

## 문제 정의

1~4단원에 `print()` 실행 예제가 반복되어, 1단원에서 이미 배운 출력 확인이 2~4단원의 핵심 목표를 가립니다. 3단원에는 이 앱에서 사용하지 않는 PC 설치·터미널·IDE 맥락이 섞여 있고, 4단원에는 브라우저 편집기와 겹치는 설명이 있습니다. 5~11단원은 핵심 용어가 처음 나올 때 짧은 풀이와 예시가 충분하지 않아 중1 입문자의 인지 부담이 커질 수 있습니다.

## 개편 원칙

- 한 소단원에는 `새 개념 1개 → 짧은 예시 → 직접 바꾸기 → 결과 설명`의 흐름을 둡니다.
- `print()`는 1.4에서 출력 창을 처음 이해하는 도구로 설명하고, 이후에는 새 개념을 보여 주는 보조 코드로만 사용합니다. 같은 목적의 단순 출력 예제는 통합·삭제합니다.
- 3단원은 “설치 없이 이 브라우저에서 실행”을 중심으로 재구성하고 PC 설치·IDE·터미널·파일 실행 안내는 학생 화면에서 제거합니다.
- 4.2 `편집기 선택하기`처럼 이미 앱 화면에서 자명하거나 3단원과 겹치는 내용은 삭제 대신 더 유용한 `코드 읽는 순서`/`오류를 만났을 때` 학습으로 교체할지 비교한 뒤, 중복이 더 크면 소단원을 줄입니다.
- 처음 등장하는 용어는 `정확한 용어 + 한 문장 풀이 + 생활 예시 또는 코드`로 설명하고, 이후에는 같은 이름을 일관되게 씁니다.
- 교재의 핵심 사실과 정답 조건은 유지하되, 빈 부분은 Python 공식 문서의 입문 설명을 근거로 보충합니다. 출처 URL은 계획·감사 문서에 기록합니다.
- 기존 Worker 실행 안전장치, 순차 잠금 해제, 다중 정답 판정, `gi-pulse`, 밝은 테마, 개인정보 비수집을 유지합니다.

## 확인할 공식 자료

- Python 공식 튜토리얼: 숫자·문자열·리스트, 흐름 제어, 함수, 자료 구조
- Python 공식 용어집: interpreter, variable, object, mutable/immutable, module, package
- Python 공식 문서의 `print()`와 실행 모델 설명

검색 결과에서 교재와 내용이 겹치지 않는 입문 설명만 선별하고, 사실·용어 정의를 임의로 단순화하지 않습니다.

## 검증 계획

- 정적 콘텐츠 분석: 1~4단원의 `print()` 반복, IDE/터미널/PC 설치 표현, 용어 첫 등장 위치를 표로 기록합니다.
- 브라우저 기준선: 375px·1280px에서 1.1→4.5 및 대표 5~11단원으로 지시 재진술·핵심 용어 설명·오류 회복을 확인합니다.
- 회귀: 모든 lesson의 제목·completion·challenge 판정과 69개 순차 잠금 해제가 유지되는지 확인합니다.
- 명령: `npm run lint`, `npm run typecheck`, `npm test -- --run`, `npm run build`.
- 브라우저: 공개가 아닌 로컬 기준선에서 320/375/1280px 가로 넘침, 키보드 포커스, 콘솔 오류를 확인합니다.
- 이미지·시뮬레이션: 새 이미지나 Canvas/WebGL 시뮬레이션은 추가하지 않습니다. 텍스트·기존 배너·코드 예제로 학습 목표를 충분히 달성할 수 있습니다.

## 완료 조건

- 1~4단원에서 같은 목적의 `print()` 안내가 반복되지 않고 각 소단원에 고유한 학습 목표가 있습니다.
- 3단원과 4단원에 PC 설치·IDE 선택·터미널 사용을 전제로 한 학생 안내가 없습니다.
- 중1 입문자가 새 용어를 처음 만날 때 풀이·예시를 확인할 수 있습니다.
- 기존 다중 정답·안전 실행·순차 진행과 전체 테스트가 통과합니다.

## 구현 결과

- `src/content/chapter2.ts`~`chapter4.ts`: 첫 출력은 1.4에 남기고, 중복된 단순 출력 단계를 읽기·결과 읽기·변수/목록 수정 실습으로 교체했습니다.

- 3단원 제목은 교재 흐름에 맞춰 유지하고 브라우저 편집기·실행 결과·안전 제한만 안내합니다. PC 설치·IDE·터미널·명령줄·파일 실행 안내는 제거했습니다.

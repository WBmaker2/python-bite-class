# 추천안 전체 반영 계획

사용자 승인: “모두 추천안으로 수정 진행해줘.”

## 최종 구성
| 대상 | 실행 결정 |
|---|---|
| 2.3 + 2.4 | 2.3에 활용 분야 말해 보기 복습을 통합, 2.4 제거 |
| 3.3 + 3.4 | 3.3에 실습 약속과 실행 제한 안내 통합, 3.4 제거 |
| 4.3 + 4.5 | 4.5에 한 줄 수정 후 세 줄 확인 활동 통합, 4.3 제거 |
| 10.4 + 10.9 | 10.4에 과목별 점수 출력 종합 도전 통합, 10.9 제거 |
| 8.3 global, 8.6 가변 인수 | 선택 참고로 전환, 필수 도전 제거. 짧은 읽기·예제로만 유지 |
| 10.2 클래스, 10.7 참조 | 선택 참고로 전환, 필수 도전 제거. 짧은 읽기·예제로만 유지 |
| 9.3 __name__ | 선택 참고 유지, 다른 참고와 함께 접힌 목차에 표시 |
| 5.6 | 자료형 알아보기로 정리. 객체·속성·__name__ 설명 제거, type() 결과 읽기에 집중 |
| 9.1 | 모듈 도구 사용에 집중, sqrt(25)의 5.0 등 익숙한 수로 짧게 설명 |

## 흐름과 진도
- 기존 생존 소단원 ID는 유지한다. 총 66개에서 62개, 필수 65개에서 57개, 선택 5개가 된다.
- 기본 이전·다음 학습은 선택 참고를 건너뛰며 필수 학습으로 이어진다. 참고는 목차의 접힌 영역에서 필요할 때 연다.
- 통합된 예전 단계 완료 기록은 대응 소단원으로 이전한다(2.4→2.3, 3.4→3.3, 4.3→4.5, 10.9→10.4). 원래 코드는 보존하고 다른 과제 코드로 덮어쓰지 않는다.
- 기존 생존 단계 완료 기록, 저장 코드는 보존한다. 제거·선택 단계는 필수 진도 집계에서 제외한다.
- 5.6의 기존 저장 코드도 실행 가능하도록 호환되는 자료형 출력 판정을 유지한다.

## 역할과 검증
- Astra: 계획, 변경 검토, ego-browser에서 학습 흐름 확인.
- Luna 콘텐츠 담당: 단원·가이드·용어·콘텐츠 테스트·업데이트 내역.
- Luna 흐름 담당: 목차 선택 참고 표시, 이전·다음 이동, 진도 이전과 회귀 테스트.
- 타입 검사·린트·전체 테스트·빌드. 실제 Python 예제 및 통합/자료형 도전 대표 실행 확인.
- 브라우저는 ego-browser 스킬 사용. 좁은 화면 및 진도/참고 건너뛰기 확인. VoiceOver 제외.
- 기존 사용자 작업 유지. 커밋·푸시·배포는 이번 요청 범위에 포함하지 않는다.

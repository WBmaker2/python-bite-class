# 교육용 상호작용 시뮬레이션 결정 기록

- 결정일: 2026-09-01
- 대상 기능: 브라우저 Python 실행기와 1.1~11.8 학습 전이
- 결정: `not-needed`

## 근거

이 앱의 코딩 영역은 입력 코드를 격리된 Worker에서 실행하고 출력과 도전 판정 결과를 보여 주는 학습 도구입니다. 학습자가 변수를 관찰하며 가설을 세우는 연속 시간 시뮬레이션이나 게임 월드, Canvas/WebGL 상태, 일시정지·스텝 실행 요구가 없습니다. 따라서 기존 DOM·Worker·텍스트 출력만으로 목표 경험을 검증할 수 있습니다.

## 점검한 경계

- 실행 제한 시간과 출력 제한, Worker 중지·재시작 계약은 유지했습니다.
- `실행 중 → 완료/확인 필요 → 학습 완료 → 다음 학습` 상태 전이를 브라우저에서 확인했습니다.
- 시뮬레이션 전문 플러그인, Canvas/WebGL, 새 데이터 시각화는 호출하지 않았습니다.
- 현재 학습 배너가 단원 맥락을 제공하므로 새 이미지는 추가하지 않았습니다.

## 후속 조건

향후 실행 결과를 시간축으로 관찰하거나 변수 값을 단계별로 조작하는 활동이 추가되면, 그때 별도 시뮬레이션 설계와 일시정지·스텝·재현성 요구를 다시 검토합니다.

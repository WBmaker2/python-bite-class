## 추가 점검: 코드에 등장하는 개념 설명 누락

추가 요청에 따라 9.2 `from ... import`의 `round()`처럼 시작 코드·예제·도전 힌트에 등장하지만 본문이나 용어집에서 충분히 설명하지 않은 함수·문법을 전 단원에서 다시 찾습니다.

- 코드 토큰과 각 소단원의 설명·용어집을 대조해 누락 후보를 목록화합니다.
- 파이썬 입문자가 실행 결과를 예측할 수 있도록 처음 등장하는 함수에는 “무엇을 받아 무엇을 돌려주는지”와 짧은 실행 예를 붙입니다.
- 기존 정답 판정과 실행 안전장치는 보존하고, 설명·용어집·예제·힌트만 보강합니다.
- 누락 검사는 회귀 테스트로 고정하고 9.2에서 `round(3.14159, 2) → 3.14`를 실제 브라우저로 확인합니다.

전수 대조에서 확인한 보강 후보는 다음과 같습니다. 변수·할당(`=`)과 리스트·`for ... in`(2.2~2.3), `if`·`True`(5.7), `+=`·`-=`(6.2), `>=`·`<=`·`==`(7.1~7.4), `round()`(9.1~9.2)와 `pi`·원주율(9.2), `type(...).__name__`·`float`·`bool`(5.6), `tuple`·`*numbers`·`len()`·`sum()`(8.6), `**` 거듭제곱(8.8), `int()`(8.9), `items()`(10.4), `add()`(10.6), `stock.get()`·기본값(11.3), 리스트 컴프리헨션·조건식(11.8)입니다. `print`, `range`, `type`, `append`, `upper`, `return`, `math.sqrt`, `math.fabs`, `dir`처럼 앞 단원에서 이미 설명된 항목은 중복 설명하지 않습니다.

## 목표

9.1 `import와 코드 묶음`에서 사용한 설명 수준(쉬운 정의 → 작은 예제 → 직접 해 볼 도전 → 구체적인 힌트)을 2~11단원의 모든 학습 단계에 적용합니다. 각 단계에서 학습자가 “무엇을 배우는지, 코드를 어떻게 읽는지, 무엇을 바꾸고 어떻게 확인하는지”를 한 화면에서 이해하도록 합니다.

## 기준선에서 확인한 문제

- 69개 단계 중 대부분의 가이드는 설명 1개와 팁 1개만 제공하며, 9.1처럼 실행 가능한 가운데 예제가 없습니다.
- 도전 과제는 `prompt`와 접힌 `hint`만 있어, 시작 결과 확인·수정 위치·통과 기준을 학생이 스스로 추측해야 합니다.
- 핵심 용어는 용어집에 있으나 본문에서 처음 만나는 순간의 쉬운 풀이와 예시가 일정하지 않습니다.
- `CONCEPT`, `TRY IT`, `YOUR TURN` 같은 영어 라벨과 짧은 피드백이 처음 배우는 학생에게 학습 순서를 충분히 설명하지 못합니다.

## 구현 범위

### 콘텐츠 모델

- `Challenge`에 선택형 `steps`, `successCriteria`, `commonMistakes`를 추가합니다.
- `LessonGuide`가 학습 목표·핵심 설명·예제 코드·관찰 팁·용어를 표현할 수 있게 확장합니다.
- 기존 `contains`, `equals`, `regex`, `appended`, `changed` 정답 판정은 유지하고, 학습 안내만 보강합니다.

### 화면

- 모든 실행/도전 단계에 `예제로 따라 하기` 블록을 표시합니다. 예제는 시작 코드를 그대로 복사하지 않고, 핵심 줄에 주목할 설명을 붙입니다.
- 도전 영역을 `도전 순서 → 통과 기준 → 막힐 때` 순서로 보여 줍니다. 기존 `힌트 보기`는 유지하되 구체적인 코드 위치와 관찰할 결과를 안내합니다.
- 학생용 라벨은 한국어를 우선하고, 필요한 영어 용어는 처음 등장할 때 괄호로 함께 설명합니다.
- 읽기 단계는 개념 설명과 자기 말로 정리할 질문을 제공하고, 실행 단계는 실행 전 예상·실행 후 관찰을 안내합니다.

### 단원별 보강 방향

1. **1단원 이 프로그램 소개**: 학습 목적, 화면 세 칸 사용법, 교재 출처·라이선스, 첫 실행의 역할을 연결합니다.
2. **2단원 파이썬 소개**: 프로그래밍 언어·버전·활용 분야를 생활 예시로 풀고, `print()`는 첫 실행 단계에서만 중심 예제로 사용합니다.
3. **3단원 설치와 실행 환경**: 브라우저 실험실, 편집기·실행 버튼·출력 창, 오류와 실행 제한을 설명합니다. PC IDE 설치 내용은 넣지 않습니다.
4. **4단원 첫걸음**: 위에서 아래로 읽기, 한 줄 수정, 예상과 결과 비교, 도움말 찾기를 반복 가능한 학습 루프로 만듭니다.
5. **5단원 기초**: 주석, 리터럴·정수·실수, 문자열, f-string·이스케이프, 변수·식별자, 자료형·객체, 들여쓰기를 각기 다른 생활 예제로 설명합니다.
6. **6단원 연산자와 수식**: 몫·나머지, `+=`·`-=`, 연산 순서와 괄호, 예산·도형 계산을 손계산→코드 실행 순서로 안내합니다.
7. **7단원 흐름 제어**: 조건의 참/거짓, `while` 종료 변화, `for`와 `range`, `break`·`continue` 차이를 출력 변화로 비교합니다.
8. **8단원 함수**: 입력(매개변수)→처리→출력/반환을 작은 기계 비유로 설명하고 지역 변수·기본/키워드/가변 인수를 단계적으로 연결합니다.
9. **9단원 모듈**: `import`, `from ... import`, `__name__`, `dir()`, 패키지와 `math` 예제를 같은 도구 상자 비유로 통일합니다.
10. **10단원 자료 구조**: 리스트·튜플·딕셔너리·집합·참조를 “어떤 상자에 담을까?” 관점에서 비교하고 순회 예제를 제공합니다.
11. **11단원 실생활 문제 해결**: 문제 정의→작은 버전→비교→함수화→결과 안내→개선→완성 프로젝트의 산출물을 단계별로 확인합니다.

## 검증 기준

- 모든 실행/도전 단계에 실행 가능한 예제 또는 시작 코드 해설, 2개 이상의 도전 순서, 구체적인 통과 기준이 있습니다.
- 새 용어는 첫 등장 본문에 `정확한 용어 + 쉬운 풀이 + 짧은 예시`가 있고 용어집과 뜻이 일치합니다.
- 2~4단원에서 `print()`만 반복하는 시작 코드는 1.4에만 남습니다.
- 브라우저 전용 과정에 PC·IDE·터미널 설치 안내가 다시 들어오지 않습니다.
- 빈 입력·오류·오답 뒤에도 학생이 힌트와 초기화로 회복할 수 있습니다.
- `npm test -- --run`, `npm run typecheck`, `npm run lint`, `npm run build`가 통과합니다.
- 실제 브라우저에서 cold start→도전→오답/회복→완료→다음 단계 흐름을 320×800, 375×812, 1280×900에서 확인하고 콘솔 오류와 가로 넘침을 기록합니다. VoiceOver는 범위에서 제외합니다.

# 중1 입문자 학습 흐름 개선 실행 계획

기준 문서: `work/grade7-linear-audit-2026-09-07.md`

## 목표

1. 코드 실행 결과가 실제로 실행한 최신 코드와 연결되도록 해 거짓 통과를 막습니다.
2. 도전 과제가 요구하는 핵심 코드 흐름을 유지하면서도 복수의 유효한 답을 인정합니다.
3. 5.6 자료형처럼 같은 개념의 여러 정상 출력 형식을 인정합니다.
4. 본문·예상 결과·시작 코드·힌트가 서로 같은 학습 행동을 가리키도록 정리합니다.
5. 브라우저 실행 준비 시간과 실제 코드 실행 제한을 구분해 느린 첫 실행의 오해를 줄입니다.

## 수정 범위

- `PlaygroundPanel`: 실행 코드 스냅샷과 현재 편집 내용을 비교하고, 수정 후 재실행을 요구합니다.
- `challengeCheck`, `types`, 도전 콘텐츠: 목표 코드 패턴을 선택적으로 검증해 무관한 변경의 거짓 성공을 막습니다.
- 2.2, 5.6, 7.4, 9.1, 11.5, 11.8: 충돌하는 지시·출력·빈 결과 안내를 교정합니다.
- `usePythonRunner`: 준비 타이머와 실행 타이머를 분리하고 학생용 복구 문구를 구분합니다.
- `updateHistory`: 이번 개선 내역을 학생이 볼 수 있게 기록합니다.

## 수용 기준

- 실행 후 코드를 바꾸고 다시 실행하지 않으면 도전 완료가 되지 않습니다.
- 11.8에서 핵심 자료 구조·함수·조건·반복을 지운 코드는 통과하지 않습니다.
- 5.6에서 `float`/`bool` 이름 출력과 `<class 'float'>`/`<class 'bool'>` 출력이 모두 통과합니다.
- 9.1을 시작 코드 그대로 실행했을 때 본문이 안내한 제곱근·절대값 두 결과가 그대로 나옵니다.
- 7.4와 11.5의 힌트를 그대로 따라 해도 목표 결과가 나옵니다.
- 준비가 모두 된 11.8의 빈 목록도 학생이 정상 상태로 이해할 수 있습니다.
- 자동 테스트·lint·build가 통과하고, 공개 앱과 같은 핵심 시나리오를 브라우저에서 재검증합니다.

구현 후 기존 검토 파일에 실제 변경·검증 상태를 덧붙입니다. 커밋·푸시·배포는 별도 요청이 없으므로 수행하지 않습니다.

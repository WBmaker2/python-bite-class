# 콘텐츠 간소화 배포 계획

사용자 승인: 커밋, 푸시, 배포.

1. Luna가 현재 변경과 원격 상태를 확인한다.
2. 이번 대화의 콘텐츠 검토·간소화·진도·검증 관련 파일만 커밋한다. 기존 elementary-webapp-ux 작업 문서는 제외한다.
3. 테스트·린트·타입 검사·빌드를 확인하고 현재 저장소의 배포 브랜치에 푸시한다.
4. GitHub Actions 배포 완료와 커밋 SHA 일치를 확인한다.
5. 공개 앱에서 62개 소단원·57개 필수·5개 선택 참고, 대표 학습 흐름을 확인한다.
6. 공개 URL과 커밋·워크플로 결과를 보고한다. HVC 등록·갤러리 동기화는 범위 밖이다.
